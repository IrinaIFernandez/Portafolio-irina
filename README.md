# Portfolio — Irina Fernández

Portfolio personal creado con React + Vite. Diseño editorial en crema, negro y dorado.

## Requisitos
- Node.js LTS instalado
- Visual Studio Code

## Cómo iniciarlo
1. Descomprimí la carpeta `portfolio-irina`.
2. Abrí esa carpeta desde VS Code.
3. Abrí la terminal integrada: **Terminal > New Terminal**.
4. Ejecutá:

```bash
npm install
npm run dev
```

5. Abrí en el navegador la dirección local que aparece en la terminal (normalmente `http://localhost:5173`).

## Antes de publicarlo, personalizá
En `src/App.jsx`:
- Reemplazá `TU_EMAIL@gmail.com` por tu correo real (aparece en dos lugares).
- Revisá los enlaces de los proyectos y repositorios.
- Agregá tu LinkedIn real si querés mostrarlo.
- Ajustá los textos de los proyectos si cambian sus funcionalidades o tecnologías.

## Compilar para producción
```bash
npm run build
```
Vite genera la versión final en la carpeta `dist`.

## Librerías
- React: construcción de la interfaz.
- Vite: servidor de desarrollo y compilación.
- lucide-react: íconos.
No hace falta instalar nada adicional: las dependencias están declaradas en `package.json`.
